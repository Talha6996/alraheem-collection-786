# Free Product-Management Tool Findings

## Scope

This note records current, first-party information about third-party mobile product-management tools. It is intended only for evaluating options; no migration or integration has been started.

## Ecwid

Ecwid’s current pricing page lists a **Starter** plan with up to ten products, but it is **not free**. The comparison table lists the Android and iOS store-management app with the paid **Venture** plan rather than Starter. Ecwid’s Android documentation says the mobile app can add products from photos, edit titles, SKUs, pricing, options, stock, availability, categories, and manage orders.

Sources:

- <https://www.ecwid.com/pricing>
- <https://support.ecwid.com/hc/en-us/articles/207102199-Ecwid-mobile-app-for-Android>

## Big Cartel

Big Cartel’s **Gold** plan is free permanently with five product listings, but its official plan comparison shows that the iOS and Android management apps are available only on paid Platinum and Diamond plans. Its Android-app documentation says the app is free to download and can add/edit products, upload photos, manage orders, discounts, and settings; those capabilities do not make the Gold plan a free mobile-management solution.

Sources:

- <https://www.bigcartel.com/product/pricing>
- <https://www.bigcartel.com/resources/help/article/big-cartel-app-for-android>

## Practical implication

Neither third-party option is a permanent free, full-featured replacement for an unlimited mobile catalogue. A custom standalone web admin remains the only route that can be designed around the current storefront and WhatsApp ordering without a third-party subscription. It can be an installable **PWA** (a phone home-screen app) and does not need to be an APK by default; a separately built Android APK is an optional, different delivery format.
