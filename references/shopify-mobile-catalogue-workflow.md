# Shopify Mobile Product Upload Workflow

The seven requested categories now exist in Shopify as automatic collections. They are populated by the product’s **Product type** field, not by Shopify’s optional standard **Product category** taxonomy.

| Storefront category | Enter this exact Shopify Product type |
| --- | --- |
| JEWELLERY | `Jewellery` |
| HANDBAGS | `Handbags` |
| LADIES SUIT | `Ladies Suit` |
| MENS SUIT | `Mens Suit` |
| BRANDED KARA | `Branded Kara` |
| BRIDAL SETS | `Bridal Sets` |
| MENS BRACELET | `Mens Bracelet` |

In the Shopify mobile app, open **Products**, tap **+**, and add the product title, media, description, price, and stock details. In the product’s organization area, set **Product type** to one value from the table exactly as written. Save the product as **Active** and make it available to the **Manus** sales channel. The automatic collection and the website’s matching category filter will then include it without a manual collection assignment.

The Shopify Product category field can still be selected for Shopify’s standardized taxonomy, but it does not control this website’s seven category links. Do not use a tag or a different spelling as a substitute for the listed Product type values.

Shopify documents that smart-collection conditions can match a product type using an exact value, and that products matching a collection condition are added automatically. [1] [2]
